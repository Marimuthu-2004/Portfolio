# Global Superstore 2016 – Sales Data Analysis

## 📌 Project Overview

This project performs an end-to-end exploratory data analysis (EDA) on the **Global Superstore 2016** dataset to uncover sales trends, regional performance, product profitability, and customer behavior insights.

## 🗂️ Project Files

| File | Description |
|------|-------------|
| `Retail Sales Data Analysis.ipynb - Colab.html` | Jupyter Notebook (HTML export) — full EDA with visualizations |
| `Retail Sales Dataset.pdf` | Project report with key findings and insights |
| `superstore_2016.xlsx` | Raw dataset — Global Superstore 2016 |
| `superstore_cleaned.xlsx` | Cleaned and processed dataset |
| `superstore_orders.cleaned_csv` | Cleaned Orders table (CSV) |
| `superstore_people.cleaned_csv` | Cleaned People/Region table (CSV) |
| `superstore_returns.cleaned_csv` | Cleaned Returns table (CSV) |

## 🛠️ Tools & Technologies

- **Python** (Pandas, NumPy)
- **Data Visualization**: Matplotlib, Seaborn
- **Jupyter Notebook / Google Colab**
- **Excel** (data inspection & cleaning)

## 🔍 Key Analysis Areas

- **Sales & Profit Trends** — Year-over-year and monthly performance
- **Regional Analysis** — Sales and profit breakdown by region and country
- **Product Category Insights** — Best and worst performing categories/sub-categories
- **Customer Segmentation** — Sales by customer segment (Consumer, Corporate, Home Office)
- **Shipping Analysis** — Impact of shipping mode on profitability
- **Returns Analysis** — Identifying high-return products and regions

## 📊 Key Findings

- Technology is the highest revenue-generating category.
- West region leads in sales; Central region shows lower profitability.
- Tables and Bookcases sub-categories show consistent negative profit margins.
- Standard Class shipping dominates but Same Day shipping yields higher profit per order.

## 📁 Dataset Source

Global Superstore 2016 — a widely-used retail dataset for data analytics practice, covering 4 years of international retail orders.
