
# Telecom Customer Churn Analysis

## 1. Project Overview
This project focuses on analyzing telecom customer data to understand customer churn patterns and customer behaviour. Python is used for data cleaning, exploratory data analysis (EDA) and data visualization.

## 2. Project Objectives
- Analyze customer demographics and behaviour.
- Understand customer churn patterns.
- Explore customer tenure and retention.
- Compare churn across telecom services.
- Analyze contract types and payment methods.
- Identify patterns that can support customer retention strategies.

## 3. Dataset Information
The dataset contains telecom customer information, including:
- Customer demographics
- Tenure
- Internet and phone services
- Contract types
- Payment methods
- Churn status

Created visualizations using Matplotlib and Seaborn, including:
- Countplots
- Stacked bar charts
- Histograms

## 8. Key Findings
The analysis explores churn patterns across customer demographics, tenure, telecom services, contract types and payment methods. Visualizations help compare customers who stayed with the company and those who left.

## 9. Business Recommendations
- Monitor customer segments with higher churn patterns.
- Improve customer engagement and support.
- Understand customer preferences.
- Review service and contract-related churn patterns.
- Develop data-driven customer retention strategies.
